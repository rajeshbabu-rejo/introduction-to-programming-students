# Introduction to Programming — student materials

**Dr. C. Rajesh Babu · Woxsen University**

Start here if you are new to programming. These two lessons introduce C through short campus scenarios. Each lesson has classroom slides, a guided lab, and a starter C file that you will complete yourself.

## What to do first

1. Download this repository using **Code → Download ZIP**, then keep the lesson folders together.
2. Open the current lesson's `resources` slide deck before class or when revising.
3. In the lab, open the lesson's `lab/README.md` and follow its checkpoints in order.
4. Open the `lab` folder in VS Code. Edit a **copy** of the starter `.c` file so you can return to the original if needed.
5. Use the compiler and build command provided in the lab guide. Ask the instructor if a compiler is not available on the lab computer.
6. Record your prediction, output, and explanation. Submit the files listed in the guide.

## Learning routine

**Learn → Do → Observe → Record → Explain → Extend → Submit**

Before running a program, predict what it will display. After running it, compare the result with your prediction. If it does not work, save the compiler message and use it to find the problem. Your explanation matters as much as the final output.

## Where to put your work

Save your completed `.c` file and evidence in a personal folder named with your student ID. Do not overwrite the supplied starter. You can use [submission_record.md](submission_record.md) to capture your observations and answers. Follow any submission instructions given by your instructor.

These materials use C11. The lab computer's compiler and any required VS Code extensions will be confirmed in class.
