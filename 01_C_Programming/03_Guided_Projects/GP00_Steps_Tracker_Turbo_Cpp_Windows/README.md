# GP00: Steps Tracker Using Turbo C++ on Windows

**Course:** BEVS72101 - Introduction to Programming  
**Faculty:** Dr. C. Rajesh Babu  
**Completion deadline:** **16 October 2026, 11:59 PM IST**

## Your task

Develop a working **Steps Tracker** in C by following the guided stages in the student workbook. You will begin with the smallest valid C program, learn how each line works, add constants and variables, accept user input, perform calculations, make decisions, test the program and complete five extension challenges.

Both parts are compulsory:

1. Upload the required work to your personal GitHub repository.
2. Submit the completed answer booklet and GitHub link through the Microsoft Form.

## Download before the lab

- [Student workbook](BEVS72101_Steps_Tracker_Turbo_Cpp_Windows_Student_Workbook.docx)
- [Starter C file](STEPTRK.C)

Download the repository with **Code > Download ZIP**, or download the two files above. Keep both files in one personal lab folder.

## Laboratory workflow

1. Open Turbo C++ on the Windows laboratory computer.
2. Open `STEPTRK.C`, or choose **File > New**, type the starter program and save it as `STEPTRK.C`.
3. Complete the workbook stages in order. Do not jump directly to the final program.
4. Use the same operating sequence after every meaningful change:

   **F2 Save > Alt+F9 Compile > Ctrl+F9 Run > Alt+F5 View Output > Esc Return**

5. Record predictions, observations, explanations and test evidence in the workbook.
6. Complete the algorithm, pseudocode, flowchart, core program and all five challenges.
7. Export or save the completed answer booklet as one readable PDF or DOCX file.

## Evidence to retain
